# Smod-Toolgun

Hello! Thanks for taking interest in making addons for my toolgun!

You can view the functions available from the toolgun in the file "SMOD FUNCTIONS.lua"
These functions can only be used after the toolgun script is loaded, as there is no hooking. You can only use them safely when your onCreate function is called.

There are two types of toolgun addons. Category and Modes. Categories lets you add files to the spawn menu, while Modes let you add more functionality to the toolgun.
To add either type of addon, you need to create a autotool, then use the sm.Smod functions properly.

There are two templates and two examples. The templates include the necessary functions for basic addons of both types.
